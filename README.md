# PINJARI JAFAR — Cloud / DevOps Portfolio

Static portfolio generated from the uploaded resume.

## Run locally
Open `index.html` in a browser, or run:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Included
- Premium responsive dark UI
- AWS / Azure / DevOps skills
- Three project case-study sections
- Architecture visualizations
- Security and observability sections
- Certifications and education
- GitHub / LinkedIn / email links
- Resume download
- Mobile navigation
- Reduced-motion support
